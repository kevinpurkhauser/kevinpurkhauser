**Certifiability Is Not a Norm of Rationality: A Reply to the Computable Conditioning Argument**

The theorem of Ackerman, Freer and Roy is a striking result about the limits of computation. The argument built on it is a different matter. It moves from a fact about what can be proved about a program to a conclusion about what rationality requires of a credal state. Each step of that move fails, and the conclusion it reaches, that rational agents must doubt their evidence, is one the argument cannot support even on its own terms.

Start with the certifiability requirement. The claim is that an updating norm binds a computable agent only if the agent can certify, from its own representation of its prior, that it can satisfy the norm. This requirement condemns far more than Kolmogorov conditionalization. Whether an arbitrary program defines a countably additive probability measure at all is not decidable. Neither is whether a set of sentences the agent believes is consistent. Applied consistently, the requirement abolishes probabilism and deductive closure together. Christensen and Smithies have argued that ideal norms are evaluative standards, not instructions an agent must be able to follow. A standard of correctness does not lose its authority because no agent can verify that it meets it. Logical omniscience is unattainable too, and a contradiction is still a defect.

The requirement is also unstable in its own terms. "Certifiable" has to mean provable in some theory, and the thesis picks ZFC. In ZFC plus Con(ZFC), the problematic prior is certifiably well behaved. So the thesis makes an agent's rational standing depend on which axioms its evaluator happens to accept. That standing would rise and fall as large-cardinal hypotheses are accepted or rejected. Rationality relativized to a metatheory is no longer recognisably rationality.

Now consider representation-dependence. Suppose ZFC is consistent. Then the presented prior and the well-behaved prior are the same measure. Their regular conditional distributions coincide almost everywhere, so the computable update that works for one works for the other. The agent holding the strange program can run the correct update. What it cannot do is prove that the update is correct. The thesis runs together satisfying a norm and being able to demonstrate that one satisfies it. The demonstration really does depend on the representation. Whether the norm is satisfied does not, because that is a fact about the function. Rescorla's Dutch book theorem for Kolmogorov conditionalization makes the same point in pragmatic terms. Vulnerability to a diachronic book is fixed by the credences and the update rule, not by the source code that encodes them.

There is a sharper point here, which I have not seen made in print. If ZFC is consistent, the two programs output identical rational approximations at every stage, forever. They are equivalent in input and output, in behaviour, and in every finite run. They differ only in their syntax. So the thesis does not make rational standing depend on computational capacity, which was supposed to be the whole motivation for computable epistemology. It makes standing depend on the text of a program, with no difference in anything either agent can do. A functionalist about credal states should regard this as a reductio of the certifiability requirement.

Next, the step from certifiability to noise. The claim that noisy channels are "the only general certifiable route" is false. Certifiable conditioning is available in several other ways:

- Discrete evidence.
- Joint distributions with bounded computable densities, of which the noise result is one corollary.
- Computable exchangeable structure, which Freer and Roy treat in work on a computable de Finetti theorem.
- Priors written in typed probabilistic languages whose constructors guarantee computable disintegration.

More importantly, the noise model does not remove exact evidence. It moves it. The agent conditions on the exact real value of the noisy reading. Computability comes from the smoothness of the likelihood, not from any inexactness in what is conditioned on. It is therefore misleading to call the result a "doubt about the exactness of one's evidence." The agent is still certain, to infinite precision, of the value it read. It has simply adopted a convenient likelihood.

There is a second objection I believe is new. The noise corollary needs a bounded density. An agent that is genuinely unsure about how noisy its channel is should mix over noise scales. Any mixture that gives positive weight to arbitrarily small noise has a density that is unbounded near zero noise, so the corollary no longer applies. To stay certifiable, the agent must be certain that its noise is no smaller than some fixed threshold. This is not a small, modest doubt. It is a dogmatic and unrevisable belief about a physical quantity, held fixed whatever evidence arrives. The thesis says this places no constraint on beliefs about the world. A lower bound on one's own measurement error is a belief about the world.

Finally, the noise belief is held for the wrong kind of reason. The agent believes its channel is noisy because believing so makes its updates certifiable, not because of any evidence about channels. This is a state-given reason, structurally like Pascal's wager. Credences adopted for their computational convenience are not thereby rational, any more than credences adopted because they are comforting.

Consider a case that sharpens the worry: an agent whose evidence is the content of its own input register. Its evidence is digital and exact by construction, and it can know this. Requiring it to believe its readings are noisy requires it to believe something it has conclusive reason to think false. If its evidence really is exact, the noise-modelling agent is the one exposed to a diachronic Dutch book, by Rescorla's result. The orthodox agent is not.

The correct lesson of Ackerman, Freer and Roy is modest. For some exact-evidence problems, no algorithm can certify the ideal update. That is a fact about the gap between ideals and their provable implementation. It is not a refutation of the ideal. It is also no reason to give up confidence in what one has observed.
