| 12 | "Suppose instead the agent learns a reading Y = Z + ξ, where ξ is independent and has a fixed computable bounded density φ ... The LICS abstract says "independent absolutely continuous noise". So the essay's hypotheses match the body corollary in the draft I could see, but not the published abstract's wording. Either check the JACM corollary and cite it by number, or write "a case of AFR's noisy-observation result (their corollary for noise with a bounded computable density)". | 13 | "Practitioners of probabilistic programming already condition on continuous data through likelihood densities. For instance, Shan and Ramsey (2017) construct such densities by symbolic disintegration." | PARTLY VERIFIED | The abstract says they compute exact posteriors, including for probability-zero observations, by symbolically transforming programs into disintegrations. Their output is a disintegration (an unnormalized kernel with respect to a base measure), which is density-like but not literally a "likelihood density". Suggested wording: "Shan and Ramsey (2017) compute disintegrations symbolically, which yields density-based conditioning on continuous observations." |
| 14 | "Kripke (1982) argued that a machine's program settles which function it computes only relative to its designer's intentions." | PARTLY VERIFIED (paraphrase slightly off) | The passage is in a long footnote; a secondary source places it at pp. 35-37. Kripke's claim, as commentators report it and as I recall it, concerns the physical machine. Which function it computes, and whether it malfunctions, is fixed only by the program as intended or stipulated by its designer. It is not that the program settles the function relative to the designer's intentions. Suggested wording: "Kripke (1982, 35-37 n.) argued that which function a physical machine computes, and so whether it has malfunctioned, is fixed only relative to the program its designer intended." The exact page and footnote number were not confirmed. |
| 15 | "It is correct if the agent's model of how intervals are reported is ignorable, for example under coarsening at random (Heitjan and Rubin 1991)." | VERIFIED, with a nuance | Heitjan and Rubin introduce CAR. Their ignorability result needs CAR together with distinctness of parameters (a priori independence in the Bayesian case). "For example under coarsening at random" is acceptable, but "under coarsening at random (with distinct parameters)" is more exact. |
| 16 | "Along a fixed nested partition, such as the dyadic intervals containing y, the resulting posteriors converge almost surely to a version of the exact posterior (Lévy's upward theorem)." | VERIFIED (mathematics, background knowledge) | The dyadic filtration generates σ(Y), so Lévy's upward theorem gives almost sure convergence for each event of a countable generating class. That is enough for weak convergence on a Polish H. |
| 17 | "The intervals an agent actually receives from a Cauchy name are not those of a fixed filtration, so for them a differentiation theorem is needed, for instance Besicovitch's theorem for centred intervals." | WRONG as applied | Besicovitch's differentiation theorem concerns balls centred at the point y. Centred balls are exactly what makes it hold for every Radon measure. The intervals from a Cauchy name, (q_i - 2^-i, q_i + 2^-i), are centred at the rationals q_i, not at y, so the cited theorem does not cover them as stated. Possible fixes: (a) cite a differentiation result for arbitrary intervals containing the point. I believe that in one dimension this holds for every locally finite Borel measure, because a covering by intervals can be refined to overlap at most 2, but I could not confirm a source, so check one such as Federer 2.8 or de Guzmán before citing. (b) Restrict to P_Y absolutely continuous and use Lebesgue differentiation for nicely shrinking sets: each named interval lies in B(y, 2^(1-i)) and has comparable length. (c) Drop "centred". |
| 18 | "Rescorla's (2018) Dutch book theorem, as I read it, applies to an agent whose update rule departs from Kolmogorov conditionalization of its own prior on a set of positive prior probability." | PARTLY VERIFIED | This is consistent with the published description: Kolmogorov conditionalization is the unique rule avoiding sure loss, and versions differ only on null sets. The hedge "as I read it" is appropriate. I could not confirm the exact hypotheses. Two caveats should be added. (i) Rescorla's setting presupposes a total update rule assigning a probability measure to each learned value, possibly measurable. A computable U that diverges or outputs partial approximations off its correct set may not be such a rule, so say how U's outputs induce a total rule. (ii) Meehan and Zhang, "Kolmogorov conditionalizers can be Dutch booked if and only if they are evidentially uncertain" (RSL, online 2020; a bibliography lists vol. 15, pp. 722-757, unverified), show that Kolmogorov conditionalizers can be Dutch booked when the chosen version is improper. This bears on sentence 19. |
| 19 | "On routes (a) and Proposition 4, the agent Kolmogorov-conditionalizes its own prior on what it learns, so Rescorla's theorems give no handle against it." | PARTLY VERIFIED | It holds given Rescorla's converse theorem. In light of Meehan and Zhang, though, the posterior should be taken to be the proper version κ(y) ⊗ δ_y on H × Y. Add one line saying so. |

Hedge it ("plausibly applies") or explain the mapping. |

PART 3. DIRECT QUOTATIONS

PART 4. FIXES, ORDERED BY SEVERITY

1. (High) Besicovitch: the theorem is for balls centred at the point, and Cauchy-name intervals are centred at the q_i. Rewrite as in item 17.
2. (High) AFR's noisy-observation hypotheses: the published abstract says "sufficiently smooth bounded density", while the body corollary I could see says "bounded computable density". Check the JACM corollary, cite it by number, or soften to "a case of".
3. (Medium) "AFR 2019, the section on positive results for densities and noise": unverified, and it looks like a section title. Replace it with the actual section or theorem number from JACM.
4. (Medium) Rescorla's Dutch book step (Sections 3.3 and 5): say how a partial computable U induces a total update rule. Cite Meehan and Zhang and specify proper versions for routes (a) and Prop. 4. Hedge the route (b) claim.
5. (Medium) Kripke: change the paraphrase so it concerns the physical machine and the designer-intended program, and add pages (pp. 35-37 footnote per secondary source; confirm).
6. (Medium) Huttegger, Walsh and Zaffora Blando: change the year to 2026 (PPR 112(1), Jan 2026, 307-324, DOI 10.1111/phpr.70079), or note "online 2025". Update the in-text year to match.
7. (Low) Remove the uncited references Garber 1983, Hacking 1967 and Weihrauch 2000, or cite them in the text.
8. (Low) Shan and Ramsey: reword "construct such densities" to "compute disintegrations".
9. (Low) "AFR's results on the discontinuity of conditioning": make it more specific (item 9).
10. (Low) Rescorla 2025: confirm end page 212 and the hyphenation of "Non-factive"/"Nonfactive"; optionally add the DOI.
