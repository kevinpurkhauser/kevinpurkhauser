## Critique
- Budget is met, but the appendix is counted, so the main text is 5250.
- Section 2 now does two jobs, setting up the framework and defending FOLLOW. Defending FOLLOW before the theorem is shown leaves the reader without motivation. Better: state FOLLOW in section 2, then defend it in section 4 once the theorem shows what is at stake.
- Section 5's "evidence-first formats are not open-ended" claim needs an explicit mini-argument. The point: Bayes' rule for a new source requires the source's likelihood, and an exact deterministic source has no density. State it as numbered steps.
- Missing: the connection to practice (Bayesian perception models already use noise likelihoods). This is a cheap and strong point for importance; add it in section 5.
- Overclaiming risk: "the only route". Must say "every route known".
