Following Conditionalization: Per-Prior
Computability Is Not Enough
Abstract. Ackerman, Freer and Roy showed that some computable priors have
conditional distributions that no algorithm can compute. A natural response is to
require that a computable agent’s prior have computable conditional
distributions. I show that, for an agent who may adopt new priors (for instance
models given as programs) or form countable mixtures of priors, this per-prior
requirement does not make conditionalization a rule the agent can follow. I
construct a uniformly computable family of priors, built from a uniform law and a
comb of tents. Each member has a continuous, computable posterior on an exact
observation, yet no single procedure updates them all, and so any ﬁxed updating
procedure is, in some state the agent can reach, exposed to a Dutch book. What
restores a single procedure is a regularity condition with ﬁxed parameters. The
thesis is about quantiﬁer order. A condition of the form “each prior is regular to
some degree” does not suﬀice. A condition of the form “there is a degree of
regularity that every reachable prior meets” does. The uniformity can come from
three sources: - ﬁxed constants in the class of admissible priors; - regularity data
supplied with each prior; - a regular model of the evidence source, which changes
the evidence.
So computability constrains rule-following credence only through conditions that
are uniform across the states an agent can come to hold. The ideal reading of
conditionalization is untouched.
1. Introduction
When a Bayesian agent learns that a continuous quantity took the value 𝑦, the
learned event has probability zero and the ratio formula is silent. The standard
answer is Kolmogorov conditionalization. The new credence is given by a regular
conditional distribution: a kernel 𝑦 ↦ 𝑃[ ⋅ ∣ 𝑌= 𝑦] that disintegrates the prior and
is ﬁxed up to observations of measure zero. (Kolmogorov 1933 gives the measure-
theoretic notion of conditional probability; regular versions came later.) Rescorla
(2018) proves Dutch book and converse Dutch book theorems for this rule, and
Rescorla (2025) extends them to scenarios in which the conditioning proposition
may be false.
Ackerman, Freer and Roy (2011, 2019; hereafter AFR) showed that the rule can
outrun computation. There are computable random variables 𝑋 and 𝑌 whose
conditional distribution of 𝑋 given 𝑌 is not computable on any set of measure one.
Computability has been used to constrain credence functions in other respects.
Lopez-Wild (2026) argues that, on countably generated spaces, there are nocomputable merely ﬁnitely additive probability measures, and Huttegger, Walsh
and Zaﬀora Blando (2026) study convergence to the truth for computable priors.
A response to AFR then suggests itself: a computable agent must hold a prior
whose conditional distributions are computable. I call this the per-prior
requirement. I treat it as a natural position rather than one I attribute to the
authors just cited. Specialists in computable analysis know that pointwise
computability does not give uniform computability. The question here is what that
distinction means for the epistemology of updating, which has not been asked.
The thesis has four parts.
1. Failure of the per-prior requirement for open agents (Proposition 2).
Some agents can adopt priors presented as programs, or form countable
computable mixtures of priors they can hold. For such agents the per-prior
requirement can hold of every member of a reachable family while no single
procedure updates them all.
2. A Dutch book consequence. It follows that any ﬁxed updating procedure
such an agent uses departs from Kolmogorov conditionalization, on a set of
positive measure, in some reachable state. By Rescorla’s theorem the agent
is then exposed to a Dutch book in that state.
3. What suﬀices (Propositions 3 and 4). A single procedure exists when there
is a ﬁxed degree of regularity that every reachable state meets, or when
equivalent information is supplied with each state, or when the evidence
comes through a ﬁxed regular channel.
4. Quantiﬁer order. The computability condition that matters for a rule-
following agent has the form “there are constants that every reachable state
meets”, not “every state meets some constants”. Each of the paper’s positive
conditions is a property of individual credence functions, but with
parameters ﬁxed across the agent’s reachable space.
The mathematics is elementary. Proposition 2 is a diagonal argument of a known
kind: it is a close relative of the non-computability of the Radon-Nikodym operator
(Hoyrup, Rojas and Weihrauch 2012) and of AFR’s results on discontinuous
conditional distributions and on the non-computability of the disintegration
operator (Ackerman, Freer and Roy 2019, 2017). The positive results apply AFR’s
theorem for bounded densities. Practitioners of probabilistic programming
already condition on continuous data through likelihood densities. For instance,
Shan and Ramsey (2017) compute disintegrations symbolically, which yields
density-based conditioning on continuous observations. What is oﬀered here is an
epistemological consequence. A computability constraint on updating cannot be
stated prior by prior with existential parameters. It needs ﬁxed parameters, and
so it is answerable to what else the agent could come to believe.
The scope is limited in four ways. - Nothing here concerns conditionalization as an
evaluative ideal. - Nothing here concerns discrete evidence. - For an agent withone ﬁxed prior that changes only by conditionalization, nothing here goes beyond
the per-prior requirement. - I treat a single observation. Iterated observation
raises further questions, which I leave aside.
2. Framework
Computable measures. I work in computable probability theory. - Spaces are
computable metric spaces. - A point is given by a Cauchy name: rationals 𝑞1, 𝑞2,…
with |𝑞𝑖 − 𝑥|<2−𝑖 . - A probability measure is computable if some program, on input
𝑘, outputs a ﬁnitely supported measure with rational weights on ideal points
within Prokhorov distance 2−𝑘  of it. The index of such a program is a measure
presentation.
Credal states and updating. A credal state is a measure on 𝐻× 𝑌, where 𝐻
collects the hypothesis variables and 𝑌 is the observation the agent is about to
learn. - An updating procedure takes an index of a presentation of a credal state,
possibly together with further data, and a name of 𝑦 as an oracle. It outputs
approximations to a posterior over 𝐻. - It is correct on a state if there is a version
𝜅 of the conditional distribution such that, for 𝑃𝑌 -almost every 𝑦 and every name
of 𝑦, its output converges to 𝜅(𝑦) at the advertised precision. - A state is updatable
if some procedure is correct on it.
Two readings of the rule. - On the ideal reading, conditionalization is a
standard. The correct kernel exists whether or not anyone computes it. - On the
followed reading, it is something the agent does, in the way someone adds by
following the rule for addition.
The followed reading is in play when a Bayesian model is oﬀered as an
algorithmic-level account of how a mind or machine learns, in the sense of Marr
(1982). It is also in play for systems that actually perform the updates.
Operations. An agent’s credal state can change in three ways: - (U) updating; -
(A) adopting a prior from a class 𝒞 of presentations, such as a model received as
a program or built from data; - (X) forming countable mixtures, with computable
weights, of uniformly presented states the agent can hold.
The reachable states are those obtainable from the initial state by these
operations.
FOLLOW. A computable agent follows conditionalization only if a single
procedure, applied to its states in the form its operations deliver them, is correct
on every reachable state that is updatable.
FOLLOW is a necessary condition only. It asks for no proof of correctness. It
places no demand on states that no procedure could update. I take the form in
which states are delivered, and the set of operations, to be facts about the agent’sarchitecture. For engineered systems they are ﬁxed by design. For human
learners, which operations they have and in what form is an empirical question
that I leave open. Kripke (1982) argued that which function a physical machine
computes, and so whether it has malfunctioned, is ﬁxed only relative to the
program its designer intended. I do not try to answer that worry. I stipulate the
architecture, and ask what follows given it.

3.3 The Dutch book consequence
Let an agent whose reachable states include the family use any ﬁxed procedure 𝑈.
By Proposition 2 there is a reachable state 𝜇𝑀  on which 𝑈’s update diﬀers from
every version of the conditional distribution, on a set of observations of positive
probability. Extend 𝑈 to a total update rule by assigning any ﬁxed measure
wherever it fails to converge. The extended rule still diﬀers from every version of
the conditional distribution on a set of positive probability. Rescorla’s (2018)
Dutch book theorem, as I read it, applies to an agent whose update rule departs
from Kolmogorov conditionalization of its own prior on a set of positive prior
probability. So such an agent is exposed to a Dutch book in that state.
So the failure of uniformity is not only a failure of rule-following. It has the
pragmatic cost that the orthodox view itself recognises, located in a particular
state. That location is the orthodox view’s own, and I accept it. The present pointis that no ﬁxed procedure avoids every such state, although each state, taken
alone, can be updated correctly.

4.2 Quantiﬁer order
The argument combines FOLLOW with the propositions.
1. (Q1) FOLLOW.
2. (Q2) The per-prior requirement says that every reachable state is updatable.
Equivalently, for each reachable state there is some degree of regularity it
meets. By Proposition 2, an agent can satisfy this while failing FOLLOW.
3. (Q3) The condition “there is an 𝐿 such that every reachable state lies in 𝒞𝐿 ”
guarantees a single correct procedure (Proposition 4). So does a single
regular channel for all reachable states (Proposition 3b), or supplied data
with known bounds (Proposition 3a). These do not show that FOLLOW is
satisﬁed, because FOLLOW is only necessary, but they remove the obstacle
it records.
4. (Q4) So a computability condition on credence functions that is ﬁt to secure
rule-following has the form ∃ parameters ∀ reachable states, not ∀ states ∃
parameters.
Q4 is the thesis. The conditions in Q3 are properties of individual credence
functions once the parameters are ﬁxed. To that extent the orthodox claim that
computability constraints attach to credence functions survives. What does not
survive is the idea that they can be stated prior by prior with the parameters left
open. The ﬁxed parameters are answerable to the agent’s whole reachable space.
Strictly, the condition is a property of agents: of a procedure together with a
reachable space. A given credence function, for instance 𝜇𝑀0
 for a halting 𝑀0 , lies
in 𝒞𝐿  for 𝐿 of order 23𝑛 . So it can belong to an agent who satisﬁes the condition,
and also to one who does not, according to what else each agent can reach.
The ﬁxed-prior agent. For an agent whose prior is ﬁxed and changes only by
(U), the per-prior requirement is all that FOLLOW asks, since its reachable states
are posteriors of one prior. A program computing that prior’s kernel then updates
every case, as an adding machine handles every pair of numbers. The present
thesis concerns agents that adopt and mix. Much real learning is of this kind:
forming a model from data, accepting a model from another agent, extending the
hypothesis space when becoming aware of new possibilities, or averaging over a
countable family of models. For such agents the prior is among the inputs to the
updating procedure.
Stored kernels. A format that stores a kernel with each state is closed under (U),
but not under (X). Re-weighting mixture components after an observation needs
the components’ densities for the observation, and a stored kernel does not
provide them. Proposition 2’s family is itself a computable countable mixture of
components with trivial kernels.Is the thesis deﬁnitional? Given FOLLOW, Q4 follows quickly. The substantive
inputs are three. The ﬁrst is FOLLOW’s quantiﬁcation over reachable states,
which I have defended for adopting and mixing agents. The second is Proposition
2, which shows that the gap between the two quantiﬁer orders is not empty for
families of a natural kind. The third is Propositions 3 and 4, which show that each
route across the gap has a recognisable epistemic cost: - ﬁxed constants restrict
which priors may be adopted; - supplied data must come with each prior and
cannot always be computed from it; - a regular channel changes what is learned.
None of the three is free. An agent that wants its priors over hypotheses
unrestricted, and needs no extra data about them, must take the third route: it
must learn only through ﬁxed regular channels, and so treat what it learns as
readings with slack.
5. Objections
Finite precision. A computable agent never receives an exact real, so perhaps
the rule it follows is ratio conditionalization on the rational intervals it receives.
That is discrete evidence. It is correct if the agent’s model of how intervals are
reported is ignorable, for example under coarsening at random together with
distinct parameters (Heitjan and Rubin 1991). It is computable if the intervals
have null boundaries under the prior; for priors with atoms, the probability of a
closed interval need not be computable. Along a ﬁxed nested partition, such as
the dyadic intervals containing 𝑦, the resulting posteriors converge almost surely
to a version of the exact posterior (Lévy’s upward theorem). The intervals an
agent actually receives from a Cauchy name are not those of a ﬁxed ﬁltration.
When 𝑃𝑌  has a density, Lebesgue’s diﬀerentiation theorem covers them instead,
because the 𝑖-th interval contains 𝑦, has length 21− 𝑖  and lies within 21− 𝑖  of 𝑦. On
Proposition 2’s family the rate of convergence depends on the halting time, so it is
not computable uniformly. I accept the convergence result as the sense in which
the exact rule governs bounded agents as an ideal. It does not supply a uniform
procedure for the exact rule, which is what following it would require.
From capacity to norm. The conclusion is conditional. If conditionalization is to
be a rule that an adopting or mixing computable agent follows, then any
computability condition that secures this must have ﬁxed parameters across its
reachable states. Nothing here tells an ideal reasoner what to believe. Section 3.3
shows, however, that the failure has a cost the orthodox view itself counts.
Dutch books for the positive routes. On routes (a) and Proposition 4, the agent
Kolmogorov-conditionalizes its own prior on what it learns. Taking the posterior
on 𝐻× 𝑌 to be the proper version 𝜅(𝑦) ⊗𝛿𝑦 , Rescorla’s theorems give no handle
against it, and neither does the result of Meehan and Zhang (2022), which
concerns improper versions. On route (b), the agent conditionalizes on the
reading. If what it really learns is the exact value of 𝑍, route (b) is notconditionalization on its total evidence, and the Dutch book theorem plausibly
applies. Route (b) is a solution only for an agent whose evidence really is the
reading.
The evaluative ideal. If Kolmogorov conditionalization was never meant as an
instruction, nothing here touches it.
6. Conclusion
The noncomputability of conditioning invites the per-prior requirement: hold only
priors whose conditional distributions are computable. For an agent that can
adopt priors given as programs, or mix them countably, this requirement can hold
of every reachable prior while no single procedure updates them all. Such an
agent, whatever ﬁxed procedure it uses, is exposed to a Dutch book in some
reachable state. What restores a single procedure is regularity with ﬁxed
parameters: a class with a ﬁxed modulus, data supplied with each prior, or a ﬁxed
regular channel. The computability condition ﬁt for a rule-following agent has the
form “some parameters suﬀice for every reachable state”. The weaker form,
“every state meets some parameters”, does not. Exact conditionalization survives
as an ideal, approached almost surely by followable updates.
