Following Conditionalization: Per-Prior Computability Is Not Enough

Abstract. Ackerman, Freer and Roy showed that some computable priors have conditional distributions that no algorithm can compute. A natural response is to require that a computable agent’s prior have computable conditional distributions. I show that, for an agent who may adopt new priors (for instance models given as programs) or form countable mixtures of priors, this per-prior requirement does not make conditionalization a rule the agent can follow. I construct a uniformly computable family of priors, built from a uniform law and a comb of tents. Each member has a continuous, computable posterior on an exact observation, yet no single procedure updates them all, and so any fixed updating procedure is, in some state the agent can reach, exposed to a Dutch book. What restores a single procedure is a regularity condition with fixed parameters. The thesis is about quantifier order. A condition of the form “each prior is regular to some degree” does not suffice. A condition of the form “there is a degree of regularity that every reachable prior meets” does. The uniformity can come from three sources:

  • fixed constants in the class of admissible priors;
  • regularity data supplied with each prior;
  • a regular model of the evidence source, which changes the evidence.

So computability constrains rule-following credence only through conditions that are uniform across the states an agent can come to hold. The ideal reading of conditionalization is untouched.

1. Introduction

When a Bayesian agent learns that a continuous quantity took the value yy, the learned event has probability zero and the ratio formula is silent. The standard answer is Kolmogorov conditionalization. The new credence is given by a regular conditional distribution: a kernel y↦P[⋅∣Y=y]y \mapsto P[\,\cdot \mid Y = y] that disintegrates the prior and is fixed up to observations of measure zero. (Kolmogorov 1933 gives the measure-theoretic notion of conditional probability; regular versions came later.) Rescorla (2018) proves Dutch book and converse Dutch book theorems for this rule, and Rescorla (2025) extends them to scenarios in which the conditioning proposition may be false.

Ackerman, Freer and Roy (2011, 2019; hereafter AFR) showed that the rule can outrun computation. There are computable random variables XX and YY whose conditional distribution of XX given YY is not computable on any set of measure one. Computability has been used to constrain credence functions in other respects. Lopez-Wild (2026) argues that, on countably generated spaces, there are no computable merely finitely additive probability measures, and Huttegger, Walsh and Zaffora Blando (2026) study convergence to the truth for computable priors.

A response to AFR then suggests itself: a computable agent must hold a prior whose conditional distributions are computable. I call this the per-prior requirement. I treat it as a natural position rather than one I attribute to the authors just cited. Specialists in computable analysis know that pointwise computability does not give uniform computability. The question here is what that distinction means for the epistemology of updating, which has not been asked.

The thesis has four parts.

  1. Failure of the per-prior requirement for open agents (Proposition 2). Some agents can adopt priors presented as programs, or form countable computable mixtures of priors they can hold. For such agents the per-prior requirement can hold of every member of a reachable family while no single procedure updates them all.
  2. A Dutch book consequence. It follows that any fixed updating procedure such an agent uses departs from Kolmogorov conditionalization, on a set of positive measure, in some reachable state. By Rescorla’s theorem the agent is then exposed to a Dutch book in that state.
  3. What suffices (Propositions 3 and 4). A single procedure exists when there is a fixed degree of regularity that every reachable state meets, or when equivalent information is supplied with each state, or when the evidence comes through a fixed regular channel.
  4. Quantifier order. The computability condition that matters for a rule-following agent has the form “there are constants that every reachable state meets”, not “every state meets some constants”. Each of the paper’s positive conditions is a property of individual credence functions, but with parameters fixed across the agent’s reachable space.

The mathematics is elementary. Proposition 2 is a diagonal argument of a known kind: it is a close relative of the non-computability of the Radon-Nikodym operator (Hoyrup, Rojas and Weihrauch 2012) and of AFR’s results on discontinuous conditional distributions and on the non-computability of the disintegration operator (Ackerman, Freer and Roy 2019, 2017). The positive results apply AFR’s theorem for bounded densities. Practitioners of probabilistic programming already condition on continuous data through likelihood densities. For instance, Shan and Ramsey (2017) compute disintegrations symbolically, which yields density-based conditioning on continuous observations. What is offered here is an epistemological consequence. A computability constraint on updating cannot be stated prior by prior with existential parameters. It needs fixed parameters, and so it is answerable to what else the agent could come to believe.

The scope is limited in four ways.

  • Nothing here concerns conditionalization as an evaluative ideal.
  • Nothing here concerns discrete evidence.
  • For an agent with one fixed prior that changes only by conditionalization, nothing here goes beyond the per-prior requirement.
  • I treat a single observation. Iterated observation raises further questions, which I leave aside.

2. Framework

Computable measures. I work in computable probability theory.

  • Spaces are computable metric spaces.
  • A point is given by a Cauchy name: rationals q1,q2,…q_1, q_2, \ldots with |qi−x|<2−i|q_i - x| < 2^{-i}.
  • A probability measure is computable if some program, on input kk, outputs a finitely supported measure with rational weights on ideal points within Prokhorov distance 2−k2^{-k} of it. The index of such a program is a measure presentation.

Credal states and updating. A credal state is a measure on H×YH \times Y, where HH collects the hypothesis variables and YY is the observation the agent is about to learn.

  • An updating procedure takes an index of a presentation of a credal state, possibly together with further data, and a name of yy as an oracle. It outputs approximations to a posterior over HH.
  • It is correct on a state if there is a version κ\kappa of the conditional distribution such that, for PYP_Y-almost every yy and every name of yy, its output converges to κ(y)\kappa(y) at the advertised precision.
  • A state is updatable if some procedure is correct on it.

Two readings of the rule.

  • On the ideal reading, conditionalization is a standard. The correct kernel exists whether or not anyone computes it.
  • On the followed reading, it is something the agent does, in the way someone adds by following the rule for addition.

The followed reading is in play when a Bayesian model is offered as an algorithmic-level account of how a mind or machine learns, in the sense of Marr (1982). It is also in play for systems that actually perform the updates.

Operations. An agent’s credal state can change in three ways:

  • (U) updating;
  • (A) adopting a prior from a class 𝒞\mathcal{C} of presentations, such as a model received as a program or built from data;
  • (X) forming countable mixtures, with computable weights, of uniformly presented states the agent can hold.

The reachable states are those obtainable from the initial state by these operations.

FOLLOW. A computable agent follows conditionalization only if a single procedure, applied to its states in the form its operations deliver them, is correct on every reachable state that is updatable.

FOLLOW is a necessary condition only. It asks for no proof of correctness. It places no demand on states that no procedure could update. I take the form in which states are delivered, and the set of operations, to be facts about the agent’s architecture. For engineered systems they are fixed by design. For human learners, which operations they have and in what form is an empirical question that I leave open. Kripke (1982) argued that which function a physical machine computes, and so whether it has malfunctioned, is fixed only relative to the program its designer intended. I do not try to answer that worry. I stipulate the architecture, and ask what follows given it.

3. The family

3.1 Construction

Let Z∈[0,1]Z \in [0,1] and I∈{0,1}I \in \{0,1\}. For n≥2n \ge 2, let EnE_n be the set of zz whose binary digits in positions nn to 2n2n are all 00. EnE_n is a union of 2n−12^{n-1} intervals of length 2−2n2^{-2n}. Let fnf_n be the continuous density that places a tent of mass 2−(n−1)2^{-(n-1)} on each of these intervals. The peak height of fnf_n is 2n+22^{n+2}, its slope is 23n+32^{3n+3}, and on the central half of each interval its value is at least 2n+12^{n+1}.

Let A=δ0⊗LebA = \delta_0 \otimes \mathrm{Leb} and Bn=δ1⊗fnLebB_n = \delta_1 \otimes f_n\,\mathrm{Leb}. Both are computable uniformly in nn.

For a Turing machine MM:

  • if MM halts at step mm, let n=m+2n = m + 2 and μM=(1−2−n)A+2−nBn\mu_M = (1 - 2^{-n})A + 2^{-n}B_n;
  • if MM never halts, μM=A\mu_M = A.

Equivalently, μM\mu_M is the countable mixture ∑npn(M)Bn+(1−∑npn(M))A\sum_n p_n(M)\,B_n + \big(1 - \sum_n p_n(M)\big)A, where pn(M)=2−np_n(M) = 2^{-n} if MM halts at step n−2n - 2 and pn(M)=0p_n(M) = 0 otherwise. Each pn(M)p_n(M) is decidable, and the residual weight is a computable real.

Lemma 1. μM\mu_M is computable uniformly in MM, and so is its mixture representation (the components A,B2,B3,…A, B_2, B_3, \ldots and the weights pn(M)p_n(M)).

Proof. Run MM for kk steps. If MM has halted, approximate the mixture to within 2−k−12^{-k-1}. If not, approximate AA to within 2−k−12^{-k-1}; the omitted weight is at most 2−k−32^{-k-3}, and total variation bounds Prokhorov distance.

3.2 Each member is tractable; no procedure handles them all

The agent observes ZZ exactly, so H=IH = I and Y=ZY = Z. If MM halts, then for each MM

PM(I=1∣Z=z)=2−nfn(z)(1−2−n)+2−nfn(z).P_M(I = 1 \mid Z = z) = \frac{2^{-n} f_n(z)}{(1 - 2^{-n}) + 2^{-n} f_n(z)}.

If MM never halts, the posterior is 00. Either way it is a continuous and computable function of zz. So every μM\mu_M satisfies the per-prior requirement.

Proposition 2. Fix any representation of μM\mu_M computable uniformly in MM, such as the measure presentation or the mixture representation of Lemma 1. Then no single procedure taking that representation as input is correct on every μM\mu_M.

Sketch. Suppose UU were correct on every member. By the recursion theorem, build a machine M*M^* that searches for two things:

  • a finite segment of a name of an observation, leaving a rational interval K⊆[0,1]K \subseteq [0,1] of possible values;
  • a finite run of UU on the representation of μM*\mu_{M^*} that reads only that segment and outputs a posterior within 1/81/8 of “I=0I = 0 for certain”.

The search must succeed. If M*M^* never halted, I=0I = 0 would be certain, and a correct UU would output that posterior on almost every observation after reading a finite segment.

When the search succeeds, M*M^* halts late enough that 2−(n−1)2^{-(n-1)} is less than half the width of KK. UU’s run is a fixed finite computation, so it gives the same output on every observation in KK. But KK contains an interval of EnE_n whose central half has positive measure, and on that half the true posterior gives I=1I = 1 probability above 2/32/3. So UU is wrong on a set of positive measure. The appendix gives details.

Three remarks.

  1. The marginal density of ZZ is at most 55 throughout the family, so a uniform density bound on the observation is not enough. What grows without bound is the modulus of continuity.
  2. Any regularity data that would rescue a procedure, such as a bound on fnf_{n}, decide whether MM halts. Run MM for about log2\log_2 of the bound many steps: if it has not halted by then, it never will. So such data cannot be computed from MM.
  3. The family is reachable by (X), as a countable computable mixture of uniformly presented, trivially updatable components. It is reachable by (X) provided AA and the BnB_n are themselves reachable, for instance as adoptable models. It is also reachable by (A) for any class 𝒞\mathcal{C} that contains it, for example the class of all measure-presented priors with continuous bounded densities. Finite mixing of finitely many known components does not generate the family. An agent that mixes finitely many models and keeps their densities can update the result (Proposition 3a). The result therefore concerns agents that can adopt priors given as programs, or mix countably.

3.3 The Dutch book consequence

Let an agent whose reachable states include the family use any fixed procedure UU. By Proposition 2 there is a reachable state μM\mu_M on which UU’s update differs from every version of the conditional distribution, on a set of observations of positive probability. Extend UU to a total update rule by assigning any fixed measure wherever it fails to converge. The extended rule still differs from every version of the conditional distribution on a set of positive probability. Rescorla’s (2018) Dutch book theorem, as I read it, applies to an agent whose update rule departs from Kolmogorov conditionalization of its own prior on a set of positive prior probability. So such an agent is exposed to a Dutch book in that state.

So the failure of uniformity is not only a failure of rule-following. It has the pragmatic cost that the orthodox view itself recognises, located in a particular state. That location is the orthodox view’s own, and I accept it. The present point is that no fixed procedure avoids every such state, although each state, taken alone, can be updated correctly.

4. What suffices

4.1 Three sources of uniformity

Proposition 3.

  • (a) Supplied regularity data. Suppose each state is given as a measure ρ\rho on HH, a computable function q(h,y)q(h, y) with ∫qd(ρ⊗λ)=1\int q\,d(\rho \otimes \lambda) = 1, a rational bound c≥qc \ge q, and a computable reference measure λ\lambda, so that the state is qρ⊗λq\,\rho \otimes \lambda. Then one procedure is correct on all such states. The posterior expectation of a bounded continuous gg is ∫gq(⋅,y)dρ/∫q(⋅,y)dρ\int g q(\cdot, y)\,d\rho \,/\, \int q(\cdot, y)\,d\rho. Both integrals involve bounded computable functions with known bounds, so they are computable relative to yy, uniformly in the data. The denominator is positive for PYP_Y-almost every yy. This is AFR’s argument for the dominated setting (AFR 2019, positive results). For Proposition 2’s family these data are not computable from MM (remark 2 above).
  • (b) A fixed regular channel. Suppose instead the agent learns a reading Y=Z+ξY = Z + \xi, where ξ\xi is independent and has a fixed computable bounded density φ\varphi. Taking H=(I,Z)H = (I, Z), ρ=μM\rho = \mu_M and q(h,y)=φ(y−z)q(h, y) = \varphi(y - z) places the state in case (a), with data computable uniformly in MM. So one procedure updates every member of the family on the noisy reading. This is a case of AFR’s result for conditioning on observations corrupted by independent noise; the derivation from (a) needs only that φ\varphi be bounded and computable. It does not update on the exact value of ZZ. It solves a different learning problem, in which what is learned is the reading.

Proposition 4 (fixed constants). Fix LL. Let 𝒞L\mathcal{C}_L be the class of measures on H×[0,1]H \times [0,1] whose density q(h,⋅)q(h, \cdot) of YY given hh, with respect to Lebesgue measure, is LL-Lipschitz for ρ\rho-almost every hh, where ρ\rho is the HH-marginal. Then one procedure, given only measure presentations, is correct on every member of 𝒞L\mathcal{C}_L.

Sketch.

  1. Each q(h,⋅)q(h, \cdot) is a probability density that is LL-Lipschitz, so it is bounded by C=1+L/2C = 1 + L/2, and PYP_Y has density at most CC.
  2. From the name of yy, find δ>0\delta > 0 with y∈(δ,1−δ)y \in (\delta, 1 - \delta). This is possible for every yy in the open interval, which has probability one. Take balls BB around yy of radius ε<δ\varepsilon < \delta.
  3. The probability of lying within η\eta of the boundary of BB is at most 4Cη4C\eta. So P(g(H);Y∈B)P(g(H);\, Y \in B) and P(Y∈B)P(Y \in B) are computable from the measure presentation, uniformly in LL.
  4. By the Lipschitz bound, dividing these by 2ε2\varepsilon approximates ∫gq(⋅,y)dρ\int g\,q(\cdot, y)\,d\rho and p(y)=∫q(⋅,y)dρp(y) = \int q(\cdot, y)\,d\rho to within ∥g∥Lε\|g\|L\varepsilon and LεL\varepsilon.
  5. Where p(y)>0p(y) > 0, which holds PYP_Y-almost surely, a positive lower bound on p(y)p(y) is found from these approximations, and the ratio then converges at a computable rate.
  6. Since a probability measure is computable when its integrals of bounded Lipschitz test functions are uniformly computable, this yields the posterior.

𝒞L\mathcal{C}_L is closed under countable mixtures, because each mixture density is a pointwise convex combination of the component densities. So an agent confined to 𝒞L\mathcal{C}_L stays there under (A) and (X), provided its adoptable class lies in 𝒞L\mathcal{C}_L. Proposition 2’s family lies in no 𝒞L\mathcal{C}_L, since q(1,⋅)=fnq(1, \cdot) = f_n has slope 23n+32^{3n+3}.

4.2 Quantifier order

The argument combines FOLLOW with the propositions.

  1. (Q1) FOLLOW.
  2. (Q2) The per-prior requirement says that every reachable state is updatable. Equivalently, for each reachable state there is some degree of regularity it meets. By Proposition 2, an agent can satisfy this while failing FOLLOW.
  3. (Q3) The condition “there is an LL such that every reachable state lies in 𝒞L\mathcal{C}_L” guarantees a single correct procedure (Proposition 4). So does a single regular channel for all reachable states (Proposition 3b), or supplied data with known bounds (Proposition 3a). These do not show that FOLLOW is satisfied, because FOLLOW is only necessary, but they remove the obstacle it records.
  4. (Q4) So a computability condition on credence functions that is fit to secure rule-following has the form ∃\exists parameters ∀\forall reachable states, not ∀\forall states ∃\exists parameters.

Q4 is the thesis. The conditions in Q3 are properties of individual credence functions once the parameters are fixed. To that extent the orthodox claim that computability constraints attach to credence functions survives. What does not survive is the idea that they can be stated prior by prior with the parameters left open. The fixed parameters are answerable to the agent’s whole reachable space. Strictly, the condition is a property of agents: of a procedure together with a reachable space. A given credence function, for instance μM0\mu_{M_0} for a halting M0M_0, lies in 𝒞L\mathcal{C}_L for LL of order 23n2^{3n}. So it can belong to an agent who satisfies the condition, and also to one who does not, according to what else each agent can reach.

The fixed-prior agent. For an agent whose prior is fixed and changes only by (U), the per-prior requirement is all that FOLLOW asks, since its reachable states are posteriors of one prior. A program computing that prior’s kernel then updates every case, as an adding machine handles every pair of numbers. The present thesis concerns agents that adopt and mix. Much real learning is of this kind: forming a model from data, accepting a model from another agent, extending the hypothesis space when becoming aware of new possibilities, or averaging over a countable family of models. For such agents the prior is among the inputs to the updating procedure.

Stored kernels. A format that stores a kernel with each state is closed under (U), but not under (X). Re-weighting mixture components after an observation needs the components’ densities for the observation, and a stored kernel does not provide them. Proposition 2’s family is itself a computable countable mixture of components with trivial kernels.

Is the thesis definitional? Given FOLLOW, Q4 follows quickly. The substantive inputs are three. The first is FOLLOW’s quantification over reachable states, which I have defended for adopting and mixing agents. The second is Proposition 2, which shows that the gap between the two quantifier orders is not empty for families of a natural kind. The third is Propositions 3 and 4, which show that each route across the gap has a recognisable epistemic cost:

  • fixed constants restrict which priors may be adopted;
  • supplied data must come with each prior and cannot always be computed from it;
  • a regular channel changes what is learned.

None of the three is free. An agent that wants its priors over hypotheses unrestricted, and needs no extra data about them, must take the third route: it must learn only through fixed regular channels, and so treat what it learns as readings with slack.

5. Objections

Finite precision. A computable agent never receives an exact real, so perhaps the rule it follows is ratio conditionalization on the rational intervals it receives. That is discrete evidence. It is correct if the agent’s model of how intervals are reported is ignorable, for example under coarsening at random together with distinct parameters (Heitjan and Rubin 1991). It is computable if the intervals have null boundaries under the prior; for priors with atoms, the probability of a closed interval need not be computable. Along a fixed nested partition, such as the dyadic intervals containing yy, the resulting posteriors converge almost surely to a version of the exact posterior (Lévy’s upward theorem). The intervals an agent actually receives from a Cauchy name are not those of a fixed filtration. When PYP_Y has a density, Lebesgue’s differentiation theorem covers them instead, because the ii-th interval contains yy, has length 21−i2^{1-i} and lies within 21−i2^{1-i} of yy. On Proposition 2’s family the rate of convergence depends on the halting time, so it is not computable uniformly. I accept the convergence result as the sense in which the exact rule governs bounded agents as an ideal. It does not supply a uniform procedure for the exact rule, which is what following it would require.

From capacity to norm. The conclusion is conditional. If conditionalization is to be a rule that an adopting or mixing computable agent follows, then any computability condition that secures this must have fixed parameters across its reachable states. Nothing here tells an ideal reasoner what to believe. Section 3.3 shows, however, that the failure has a cost the orthodox view itself counts.

Dutch books for the positive routes. On routes (a) and Proposition 4, the agent Kolmogorov-conditionalizes its own prior on what it learns. Taking the posterior on H×YH \times Y to be the proper version κ(y)⊗δy\kappa(y) \otimes \delta_y, Rescorla’s theorems give no handle against it, and neither does the result of Meehan and Zhang (2022), which concerns improper versions. On route (b), the agent conditionalizes on the reading. If what it really learns is the exact value of ZZ, route (b) is not conditionalization on its total evidence, and the Dutch book theorem plausibly applies. Route (b) is a solution only for an agent whose evidence really is the reading.

The evaluative ideal. If Kolmogorov conditionalization was never meant as an instruction, nothing here touches it.

6. Conclusion

The noncomputability of conditioning invites the per-prior requirement: hold only priors whose conditional distributions are computable. For an agent that can adopt priors given as programs, or mix them countably, this requirement can hold of every reachable prior while no single procedure updates them all. Such an agent, whatever fixed procedure it uses, is exposed to a Dutch book in some reachable state. What restores a single procedure is regularity with fixed parameters: a class with a fixed modulus, data supplied with each prior, or a fixed regular channel. The computability condition fit for a rule-following agent has the form “some parameters suffice for every reachable state”. The weaker form, “every state meets some parameters”, does not. Exact conditionalization survives as an ideal, approached almost surely by followable updates.
