# Kill round: C05 (misleading by design) -- VERDICT: KILLED
(Condensed record of the refuter's report; 11 tool uses, snippet-level.)
- Premise (2) true only under correct anticipation, where lies do not deceive (Sobel, JPE 128(3) 2020: lying without deception and vice versa); so the equivalence compares two non-deceptive regimes.
- With hearers who take assertions at face value (the setting of the debate), liars reach non-Bayes-plausible, systematically false posteriors that truthful disclosure cannot: the thesis "any point a liar could reach" is false.
- Bayes-plausible posteriors are calibrated, so the model drops misleading as well.
- Equivocation: precommitment to an experiment vs assertoric commitment (Viebahn, J Phil 118(6) 2021; Stokke; Pepp).
- Target is a strawman: Saul builds cases with equal resulting belief; defences of the asymmetry rest on trust, responsibility, virtue, common good (Strudler 2010, Adler, Webber 2013, Berstler 2019). Commitment-based grounding already mainstream.
- Manipulation via committed truthful disclosure already in Thorstad, "Exploitative informing" (BJPS).
- Possible different paper: characterize the extra (non-Bayes-plausible) region liars reach against trusting hearers and ask whether it tracks the moral asymmetry.
