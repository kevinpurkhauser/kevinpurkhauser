1. The problem (500)

## Critique of round 1
- Structure: sections 3 and 6 both present theorems; splitting the mathematics into two places makes the argument in 4 rely on things not yet stated (the anti-tracking world uses a lemma introduced nowhere). Better: introduce all the formal facts the core argument needs in one place, and keep only the testing generalization later.
- Redundancy: "conditional calibration" appears in 2 (as a strengthening), 5 (as an objection). Choose: build the strongest view in 2 and run the argument against it in 4; then objections in 5 are only the ones that are not strengthenings.
- Vagueness: "CR sufficiency" is not formulated. The argument must specify what calibrationism claims (a schema with parameters: conditioning family, range of worlds, limiting or finite), so that the argument can be shown to work for every value of the parameters.
- The barometer case argues against unconditional calibrationism only; against the strongest (conditional) view it fails. So the core argument must not rest on it. Core should be: dominance + anti-tracking world, which work for every parameter value. Barometer and testimony cases become illustrations.
- Missing objections: (a) "calibration was only ever meant as necessary + part of a package" (then the thesis is about sufficiency only: fine, but must say that calibrationist reliabilism as stated in SEP is a biconditional); (b) Humean collapse; (c) comparative reliability; (d) "the anti-tracking world is not a nearby world" (answer: dominance makes the range irrelevant for the uninformed process's score; the anti-tracking world matters only to show that the score is not measuring reliability; and any process is assessed in its actual world, which could be one).
- Positive upshot too thin; the competition values contribution: the upshot should show what the theorems teach (calibration is a consequence of chance-matching but not conversely; reliability must be benchmarked against chance given grounds; this is not testable by track record, which explains why calibration looked attractive and why it fails).
- Missing: precise statement of what "uninformed" means.
- Word budget plausible (6000). Need a short appendix with proofs of the own lemmas.
